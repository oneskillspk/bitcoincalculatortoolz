## ✨ Core Calculator Ecosystem

### **Available Now** 🚀

#### **1. Profit & Loss Calculator**
The most powerful P&L tool in the market. Model entry/exit strategies, multi-position portfolios, and complex trade scenarios with fee structures and slippage calculations.
- **Multi-position support** - Track 100+ trades simultaneously
- **Dynamic fee calculation** - Account for exchange, network, and custom fees
- **Scenario comparison** - A/B test trading strategies
- **Real-time updates** - Live price feeds from 50+ exchanges

#### **2. DCA (Dollar-Cost Averaging) Calculator**
Visualize the exponential power of consistent Bitcoin investing with configurable intervals and variable investment amounts.
- **Flexible intervals** - Daily, Weekly, Monthly, Quarterly, Annual
- **Historical backtesting** - Test against 10+ years of price data
- **Volatility analysis** - See impact of market cycles
- **Tax loss harvesting** - Identify optimization opportunities

#### **3. What If Investment Calculator**
Explore alternate financial futures. See how strategic investments made at any historical point would have performed through today and projected scenarios.
- **Historical date picker** - Any date in Bitcoin's history
- **Compound projection** - Forward scenarios with configurable growth rates
- **Market cycle analysis** - Identify bottoms and peaks
- **Risk modeling** - Downside and upside scenarios

#### **4. Retirement Planner**
Professional-grade retirement planning with dual-mode calculation: forward modeling and reverse goal planning.
- **Forward Mode** - Project portfolio value to retirement date
- **Goal Planner Mode** - Calculate steps needed to reach financial targets
- **Inflation adjustment** - Real vs. nominal returns
- **Life expectancy modeling** - Plan for 30+ year retirements
- **Withdrawal strategies** - 4% rule and custom algorithms

#### **5. HODL Strategy Calculator**
Long-term position tracker for buy-and-hold Bitcoin accumulators. Visualize multi-year wealth accumulation.
- **Time period analysis** - From 1 year to 20+ years
- **Cost basis tracking** - Accurate tax lot accounting
- **Accumulation schedules** - Fixed or variable contributions
- **Milestone tracking** - Watch your milestones achieved in real-time

#### **6. Mining Profitability Calculator**
Professional mining ROI calculator for hardware operators and mining pool participants.
- **500+ hardware profiles** - Pre-loaded ASIC miner specifications
- **Real-time difficulty adjustment** - Current network parameters
- **Pool fee structures** - All major pools (F2Pool, Antpool, etc.)
- **Electricity cost modeling** - Regional rate input
- **ROI/Break-even calculation** - Days to profitability
- **Hardware depreciation** - Realistic lifespan projections

#### **7. Bitcoin Converter**
Real-time, multi-currency conversion with historical pricing and rate watching.
- **60+ fiat currencies** - Every major (and minor) global currency
- **Live rates** - Updated every 1-5 seconds
- **Historical conversions** - Look up any date
- **Batch operations** - Convert multiple amounts at once
- **Offline support** - Cached rates for intermittent connectivity

## 🚀 Getting Started (Development & Deployment)

### **Prerequisites**

- **Node.js** 18+ (or 20+ for best performance)
- **npm** 9+ or **yarn** 4+
- **Git** 2.38+

### **Development Setup (3 Minutes)**

```bash
# 1. Clone the repository
git clone https://github.com/oneskillspk/btccalctoolsnw1.git
cd btccalctoolsnw1

# 2. Install dependencies
npm install
# or with yarn
yarn install

# 3. Start development server
npm run dev
# or
yarn dev

# Open http://localhost:5173 in your browser
```

### **Development Commands**

```bash
# Development with hot reload
npm run dev

# Production build
npm run build

# Preview production build locally
npm run preview

# Run linting
npm run lint

# Generate sitemap (for SEO)
npm run sitemap

# Run quality audits
npm run audit:app
npm run audit:schema
npm run audit:internal-links

# Run tests
npm run test

# E2E testing with Playwright
npm run test:e2e
```

### **Environment Variables**

Create a `.env.local` file in the project root:

```env
# API Configuration
VITE_API_BASE_URL=https://bitcoincalculator.tools
VITE_WEBSOCKET_URL=wss://bitcoincalculator.tools

# Data Providers
VITE_COINGECKO_API_KEY=your_key_here
VITE_CRYPTOCOMPARE_API_KEY=your_key_here

# Analytics (Optional)
VITE_GTAG_ID=G_XXXXXXXXXXXX
VITE_HOTJAR_ID=your_hotjar_id

# i18n Configuration
VITE_DEFAULT_LANGUAGE=en
VITE_SUPPORTED_LANGUAGES=en,tr

# Feature Flags
VITE_BETA_FEATURES=false
VITE_ENABLE_EXPORT_PDF=true
```

### **Production Deployment**

#### **Vercel (Recommended)**

```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel deploy --prod
```

#### **Docker**

```bash
# Build image
docker build -t btc-calc:latest .

# Run container
docker run -p 3000:3000 btc-calc:latest
```

#### **Static Hosting (AWS S3 + CloudFront)**

```bash
npm run build
aws s3 sync dist/ s3://your-bucket --delete
```
