# Long-Tail Keyword Research & 90-Day SEO Roadmap

Deliver a comprehensive long-tail keyword research package for bitcoincalculator.tools, grounded in **live Semrush data** (not guessed numbers) plus competitive and AI-search analysis. Output is a research report — no code changes.

## Scope

- Target: bitcoincalculator.tools (worldwide, English primary, TR secondary)
- Niche: Bitcoin/crypto calculators (49 tools already live: DCA, tax, mining, loan, arbitrage, halving, retirement, etc.)
- Audience: crypto investors, HODLers, miners, tax filers, beginners → advanced

## Research Steps

1. **Baseline the site** — `domain_analysis` on bitcoincalculator.tools + `top_pages` to see what already ranks and where the traffic comes from.
2. **Competitor discovery** — `competitive_analysis` to auto-find 5–10 direct competitors (e.g. CoinGecko calculators, Swan DCA, CryptoTaxCalculator, WhatToMine, NiceHash calc, CoinCodex).
3. **Seed keyword research** — `keyword_research` on ~15 seed heads: "bitcoin calculator", "dca calculator", "bitcoin tax calculator", "bitcoin mining calculator", "bitcoin loan calculator", "satoshi converter", "bitcoin halving", "bitcoin profit calculator", "btc to usd", "bitcoin retirement", "bitcoin arbitrage", "stack sats", "bitcoin what if", "lightning fees", "bitcoin liquidation".
4. **Long-tail expansion** — pull related + question variations from each seed (Semrush returns "Related" and "Questions" arrays). Target 300+ unique long-tails.
5. **SERP + difficulty check** — `serp_analysis` on top ~30 shortlisted candidates to confirm KDI, top ranking domains, and gap opportunities.
6. **Head-to-head** — `compare_domains` against 2 strongest competitors for context.

## Report Structure (final deliverable)

Organized markdown with tables:

1. **Executive summary** — site's current SEO baseline (traffic band, AS, keyword count), top 3 opportunities.
2. **300+ long-tail keywords** grouped by the 11 intent buckets you listed, each row: keyword · intent · volume · KDI · competition · CPC · business value · conversion potential · priority score (1–10).
3. **Search intent analysis** — for each cluster (not every single keyword), why users search, problem solved, ideal content format.
4. **Semantic / entity map** — related entities, LSI, NLP co-occurrences, supporting topics per pillar.
5. **AEO/GEO section** — keywords likely to surface in AI Overviews / ChatGPT / Perplexity, with answer-first content recs, FAQ opportunities, schema markup pointers, voice search patterns.
6. **Competitor gap analysis** — long-tails competitors rank for that this site doesn't, low-competition gaps, untapped content ideas.
7. **Content cluster strategy** — pillar pages, topic clusters, supporting articles, FAQs, glossary, comparison pages, with internal-linking map (leveraging the 49 existing calculators + `calculatorMeta` slugs).
8. **Local SEO section** — light coverage since the site is worldwide, but include country-modifier long-tails (India, UK, Germany, Australia, Turkey tax/regulation queries) since regional tax calculators already exist.
9. **Prioritization** — Quick Wins / Medium-Term / Long-Term Authority buckets, plus featured-snippet & PAA opportunity flags.
10. **90-Day publishing plan** — week-by-week table (12 weeks): target keyword · intent · content type · suggested H1 · meta title · meta description · internal links · CTA · expected impact.
