- `partial` — keyword appears in body copy but not fully aligned (missing from title, H1, or lead).

## How to add a keyword to this map

1. Confirm the target keyword has real search volume (SEMrush or Ahrefs).
2. Pick a single owning URL — never assign the same keyword to two pages.
3. Insert the keyword once in the page title, once in the H1, once in the first 100 words.
4. Set status to `done` in the table above.
5. Re-run `node scripts/audit-internal-links.mjs`.
